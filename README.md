# RockBlaster

RockBlaster is a 2D arcade shooter made in Lua using PICO-8. The goal is to destroy incoming asteroids, beat the mini boss, and get to the highest level possible.

As the levels progress, asteroid spawns increase, velocity increases, and the boss's health increases as well. The player can also charge up a plasma beam to destroy multiple asteroids at once.

## Controls

- Arrow Keys: Move the spaceship
- Z: Shoot
- X: Use plasma beam (when charged)
- X: Continue or restart after a level ends

## Features

- Randomized asteroid spawning
- Increasing difficulty across levels
- Collision detection and enemy health
- Charge-based plasma beam
- Custom sprites and sound effects

## Built With

- Lua
- PICO-8 Game Engine

## Running the Game

Open the .p8 cartridge in PICO-8 and type: run

The game can also be played in a browser using the HTML export in my portfolio
